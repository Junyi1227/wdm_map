## 從照片可辨識的外形

1. 長矩形主體，正面較寬，兩側較短；白色／淺灰石材與綠色簷帶形成明顯對比。
2. 巨型圓柱位於外圍，柱頭、柱腳有較寬環帶；玻璃立面退在柱列後方，柱廊空間不能被封成實心牆。
3. 正面有深色綠藍玻璃與水平樓板／欄板分帶；大屋簷同時覆蓋正面及側面柱廊。
4. 上方有白色退縮樓體、小窗、開放露台與長條頂棚／棚架；你提供的冬季圖可補這部分的高視角輪廓。
5. 基座前方可見曲線及簷下空間，側邊有階梯／坡道。照片不夠完整，先獨立拆件，避免AI把山坡變成牆或把橋和湖岸黏住。

不要生成三角山牆、宮殿式屋頂、八角亭屋頂、隨機尖塔或多餘對稱翼樓。不要把湖中亭、松樹、山、人物、噴泉、倒影及積雪變成建築本體。

## 建議拆件

主體與玻璃立面／16根外柱／大屋簷與柱廊／上部白色退縮量體／露台與棚架／下層基座及坡道。先生成外形，之後再清理柱間、門口、窗面與模型面數。

遊戲模型維持可愛簡化、外形可辨識；保留主要輪廓及柱列節奏，窗戶小分格可簡化。尺寸未實測，AI輸出通常也是任意尺度，之後統一換算成公尺。不要用「照片看起來很大」直接決定真實長寬高。

## 仍缺的角度

最重要的是完整背面，其次是垂直屋頂俯拍、無樹木遮擋的兩側短立面，以及下層入口與坡道連接。2013背側施工局部只可補有限線索，不能當成現況背立面。沒有實景證據的部分，AI會自行猜測，需標為推定。

夜景適合核對照明，不能把藍、紫、粉色燈光誤當白天柱材的固有顏色。聯絡表只是選圖預覽，不建議整張丟入單圖轉3D，容易長成多棟拼接。
