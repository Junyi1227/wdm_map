# 月明湖對岸石頭造景與瀑布亭

依使用者提供的照片與後續文字修正，正面由左側少量低石逐步升高至中央瀑布，再向右降低。底部較寬、頂部較窄，前側保持陡峭，具有一定厚度。

岩壁、靜態水流及頂部亭子拆成三個GLB；前後通路沿用原地圖路網，未製作白色樓梯、人工坡道或後坡入口按鈕。湖岸下層石景暫不製作。先前新增的坡道高度事件已撤除。

工作比例：底寬約50m、底部前後深約21m、頂部約8×9m，瀑布高約15m；全部是外形示意，非實測。未改寫原生地形、既有道路與湖岸。

`model/landmark.blend` 可編輯個別岩石；`landmark.glb` 為完整模型，`map-*.glb` 是供GDevelop使用的標準化分件。模型原點偏移記於 `model/map-parts.json`。來源照片見 `references.json`；圖冊的背面與尺寸仍為推定。

主體已移除整片斜坡／平面基體，改由獨立石塊交錯堆疊；底層較寬、上層收窄，亭下有支撐石。各石塊可在Blender中分別調整。

後續配置：整組左移並旋轉8度避讓湖邊道路，模型GLB幾何保持不變。山側原步道已局部改線到亭後附近再向右銜接，並局部調整原生地形高程。位姿與改線資料見source-data/lake-rocks-map-pose.json、source-data/trail-adjustments.json。
