## 後續免費建模流程（待照片核對）

- [Meshy 官方方案](https://www.meshy.ai/pricing)：查閱時免費方案每月100 credits，最多下載10個 **Meshy 6 Lite** 模型；生成數仍受額度限制。工作區確實可選6 Lite，但本輪未登入、未實際生成。免費輸出授權需保留CC BY 4.0署名等條件；多視角及較新模型不能一概視為免費。
- [Tripo 官方模型限制](https://www.tripo3d.ai/product-doc/ai-3d-models/h-series-hd-model)：免費匯出支援 **H2.5**，其他版本、貼圖及重拓撲功能須依當時方案核對。不自動付費升級。免費輸出的權利及署名條件也需在匯出時確認。
- [Blender GLB 匯出說明](https://docs.blender.org/manual/en/4.4/addons/import_export/scene_gltf2.html)：整理輪廓、移除背景、清理破面、減面並統一材質後，交付含材質的GLB與可編輯.blend。

每個單體最多先試兩次AI生成，記錄模型版本、輸入照片、花費及失敗原因。輪廓仍不正確再改照片輔助的簡化建模。尚未生成，不能把登入失敗算成已試做兩次。

依使用者後續指示，先製作駱駝石、圓山八角亭、禱告山三個初稿；四面預覽及獨立GDevelop模型測試見模型交付。待確認風格後再安排其他地標；未放進核心區。

## 之後的交付規格

公尺為單位；無可靠尺寸則標「估計」。單體目標5,000–20,000三角面，複雜單件上限30,000，大型地標拆件。貼圖預設1K，必要時2K。單色材質若已足夠，不為達到貼圖尺寸硬加圖片。亭子入口與柱間保持開放；水流留待GDevelop效果整合。

每個完成件交付GLB、.blend、四面預覽、來源與尺寸紀錄。在獨立GDevelop測試專案檢查材質、近看、背面、載入、儲存及重開。未通過項目不得標成完成。

## 重建圖冊

`python3 landmarks/tools/build_catalog.py` 離線產生圖冊與上傳素材；只需要Python標準函式庫。`collect.py` 與 `assemble.py` 是可選的來源蒐集工具，需要網路及Pillow，重新抓圖會受網站內容變更影響。來源頁HTML快取在忽略的 `.cache/landmark-pages/`，圖冊不依賴快取或網路。

316會館已於2026-11-11依使用者指示改採本機建模，GLB、Blender檔及五個拆件見 [316會館模型](models.html#02-hall-316)。不需要訂閱模型生成服務；已放入核心地圖月明湖東側，點「316會館」可定位。
